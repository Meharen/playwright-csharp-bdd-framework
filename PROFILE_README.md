## Featured Project

### [Playwright C# BDD Framework](https://github.com/Meharen/playwright-csharp-bdd-framework)

A C# UI automation framework using Playwright, Reqnroll, and xUnit. The scenarios cover form entry, login, nested frames, employee information, and performance search against public demo sites.

- Page classes and locator objects organize browser interactions.
- Reqnroll features and step definitions express test flows as BDD scenarios.
- ExcelDataReader supplies form data, and ExtentReports records test results.
- The driver includes launch paths for Chromium, Chrome, Edge, Firefox, and WebKit.

See the project README for setup instructions, test commands, and current limitations.
